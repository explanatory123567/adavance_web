# 3D Component Model Library

Store each component's 3D model in its matching folder:

- cpu/ -> CPU models
- gpu/ -> Graphics card models
- motherboard/ -> Motherboard models
- ram/ -> RAM stick or kit models
- storage/ -> SSD / NVMe models
- psu/ -> Power supply models
- case/ -> PC cases
- cooler/ -> CPU coolers
- fans/ -> Case fans

Recommended naming:

- cpu.glb
- gpu.glb
- motherboard.glb
- ram.glb
- storage.glb
- psu.glb
- case.glb
- cooler.glb
- fans.glb

Example path:

- /models/ram/ram.glb

The project can reference these paths in the builder and admin model assignment flow.
